# Codical Health design sources

This directory preserves high-resolution source and reference images used to
produce optimized application assets.

- `brand/` contains approved brand reference artwork.
- `landing/` contains the lossless source images for landing-page feature cards.

These files are intentionally excluded from Vercel deployments. Runtime-ready
SVG, WebP, PNG, and animated assets live under `client/public/assets/`.
