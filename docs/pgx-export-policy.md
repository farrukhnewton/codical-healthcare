# PGx Export Policy

Permitted formats are PDF review report, CSV coding worksheet, and JSON structured analysis. No claim-submission file is permitted.

Exports must be user initiated, owner/tenant scoped, audited, stored privately, and assigned an expiry. Filenames use opaque identifiers and contain no unnecessary PHI. CSV fields beginning with formula-trigger characters are neutralized. Every report includes evidence versions, limitations, jurisdiction context, and manual-review status.

Phase 1 PDF/base64 export exists. Persisted Phase 2 export records, expiry cleanup, CSV/JSON endpoints, and deletion verification remain completion gates.
