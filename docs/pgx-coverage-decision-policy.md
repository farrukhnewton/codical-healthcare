# PGx Coverage Decision Policy

Allowed states are:

- `supported`
- `not_supported`
- `insufficient_evidence`
- `jurisdiction_not_configured`
- `source_outdated`
- `manual_review`

A decision requires a valid state/territory, MAC, date of service, current source release, verified document-jurisdiction link, and date-effective code relationship. A matching “listed” row is not automatically “supported.” Missing or pending evidence fails to a non-affirmative state.

The product must never present “covered,” “guaranteed,” “payable,” or “approved” without payer, jurisdiction, date, and source qualification. A59915/L39995 are not nationwide policies merely because the application serves all states.
